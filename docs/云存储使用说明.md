# 苍穹外卖云存储

Bucket：`lay-java`。地域：广州，`cn-guangzhou`。Endpoint：`https://oss-cn-guangzhou.aliyuncs.com`。

## 第一次配置

1. 打开桌面的 `cqwm` 文件夹，双击 **配置云存储.cmd**。
2. 在本地窗口依次输入有效的 AccessKey ID、AccessKey Secret。输入不回显；请优先使用已轮换的新凭证。
3. 工具将两项凭证用 Windows DPAPI 加密保存在 `.local/oss-credentials.json`，仅当前 Windows 账号可解密；该目录已被 Git 忽略。
4. 工具上传一个小文本文件，核对其大小后尝试删除。出现“OSS 上传连接成功”代表云端检查通过。测试对象只位于 `sky-take-out/connection-check/` 下。
5. 双击 **启动项目.cmd**。如果已有服务运行，先双击“停止项目.cmd”，再启动。启动脚本自动解密凭证并通过当前进程的环境变量传给 Java，不把明文写入配置文件。

本地配置工具只验证 OSS，不连接 MySQL。启动完整网站时仍需本地 MySQL 密码。

## 上传图片

登录后进入 **菜品管理**，点击“新增菜品”或“编辑”，在表单中点击“上传图片”。套餐管理仍可在“图片素材”区域选择图片，点击“上传到云端”。支持 PNG、JPEG、WebP，最大5MB；服务端会检查文件内容的格式标识，不信任文件名或浏览器声明的类型。

上传成功后会显示预览和图片标识。图片保存在 `sky-take-out/images/` 下，名称由服务器随机生成。

Bucket 的公开/私有权限不会被程序更改。预览链接签名后可使用15分钟；应保存 `objectKey` 图片标识，后续再生成临时链接，避免把过期 URL 作为永久图片地址保存。

## 接口与配置

- `POST /admin/common/upload`：multipart/form-data，字段名 `file`。需要登录 `token` 请求头。
- `GET /admin/common/file-url?objectKey=...`：刷新已上传图片的临时链接。需要登录。
- 成功响应的 data 包含 `objectKey`、`url`、`expiresInSeconds`。
- 继续使用 `sky.alioss` 配置前缀、AliOssProperties 和新增的 AliOssUtil、AliOssConfiguration、OssStorageService、CommonController。
- 阿里云 SDK 使用 HTTPS 和 V4 签名；客户端每次使用后释放连接资源。
- 也可在 IDEA 的运行环境变量中设置 `ALI_OSS_ACCESS_KEY_ID`、`ALI_OSS_ACCESS_KEY_SECRET`，无需本地加密文件。

## 权限与错误

凭证只需访问此 Bucket 中项目使用的对象前缀。上传使用 `oss:PutObject`，预览和核对使用 `oss:GetObject`；清理自建测试文件使用 `oss:DeleteObject`。工具不要求修改 Bucket ACL 或授予全部云服务权限。

- `InvalidAccessKeyId`：核对凭证是否有效、是否已经停用。
- `SignatureDoesNotMatch`：核对 Secret、地域和本机时间。
- `AccessDenied`：检查上述对象权限是否覆盖 `lay-java/sky-take-out/*`。
- `OSS_CHECK_OK_TEST_FILE_RETAINED`：上传、读取已成功，但因删除权限不足保留了自建测试文件。
- 密钥轮换后再次运行“配置云存储.cmd”，重新启动项目。
