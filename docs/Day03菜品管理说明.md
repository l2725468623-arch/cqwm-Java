# 菜品管理使用说明

已在桌面 `cqwm` 项目中完成菜品新增、修改、删除和分页查询，前后端均已接通。

## 开始使用

1. 保持本机 MySQL 运行，双击项目中的 **启动项目.cmd**，在本地窗口输入数据库密码。
2. 打开 `http://localhost:8080/#/login`，登录后进入 **菜品管理**。
3. 如果没有可选分类，先在 **分类管理** 新增一个“菜品分类”并启用。
4. 图片上传使用已配置的阿里云 OSS。启动脚本会加载本地加密凭证。

## 四项功能

| 功能 | 操作与结果 |
| --- | --- |
| 新增 | 填写名称、分类、价格，上传图片；可填写描述和多组口味。默认停售。保存时同时写入菜品和口味。 |
| 修改 | 点击“编辑”，回显菜品、图片和口味；保存后统一更新。创建时间和创建人保留，修改信息自动更新。 |
| 删除 | 支持单条删除、勾选当前页后批量删除；同步删除关联口味。起售中或已被套餐引用的菜品不能删除，批量中任一项不符合条件则整批保留。 |
| 分页查询 | 按名称模糊搜索，可同时筛选分类、售卖状态；支持每页10、20、50条及上一页、下一页。重置恢复默认条件。 |

价格必须大于0，最多两位小数。口味可填写“辣度”，选项填写“不辣，微辣，中辣”，多个选项用中英文逗号分隔；保存为课程中使用的 JSON 数组字符串。

图片支持 PNG、JPEG、WebP，最大5MB。数据库保存 OSS 的 `objectKey`，页面通过临时签名链接预览。删除菜品会保留云端图片，避免误删其他记录正在使用的图片。

## 对应代码

以下路径相对于桌面 `cqwm` 项目根目录：

- `sky-pojo/.../dto/DishDTO.java`：接收菜品和口味；`DishPageQueryDTO.java`：接收查询条件。
- `sky-pojo/.../vo/DishVO.java`：返回菜品、分类名称和口味。
- `sky-server/.../controller/admin/DishController.java`：接收页面请求。
- `sky-server/.../service/impl/DishServiceImpl.java`：处理分类校验、口味、事务和删除保护。
- `sky-server/.../mapper/DishMapper.java`、`DishFlavorMapper.java`：调用对应 XML 中的 SQL。
- `sky-server/src/main/resources/mapper/`：菜品、口味的新增、查询、修改和删除 SQL。
- `sky-server/src/main/resources/static/`：菜品列表、编辑弹窗、交互和样式。

新增和修改通过已有 `@AutoFill` 自动填充时间及当前登录员工；事务保证菜品与口味一起成功或一起回滚。

## 接口

管理端接口均要求登录后的 `token` 请求头。

| 方法 | 地址 | 用途 |
| --- | --- | --- |
| POST | `/admin/dish` | 新增菜品及口味 |
| PUT | `/admin/dish` | 修改菜品及口味 |
| GET | `/admin/dish/{id}` | 详情和编辑回显 |
| GET | `/admin/dish/page?page=1&pageSize=10&name=&categoryId=&status=` | 筛选及分页 |
| DELETE | `/admin/dish?ids=1,2` | 单条或批量删除 |
| POST | `/admin/dish/status/{status}?id=1` | 起售1、停售0 |
