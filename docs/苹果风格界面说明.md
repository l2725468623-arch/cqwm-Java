# 前端视觉更新

桌面 `cqwm` 项目已统一为苹果产品落地页方向的视觉：纯白与纯黑背景、大面积留白、居中大标题、简短文案、`#0071e3` 蓝色胶囊按钮、克制的线条与柔和光影。

- 登录前：产品落地页、金属餐罩主视觉、功能介绍和黑色收尾区；“进入管理中心”打开真实登录弹窗。
- 登录后：轻薄顶部导航、产品风格工作台、统一的菜品/分类/员工列表与编辑弹窗。
- 手机端：自适应排版、可折叠菜单、可滚动表格与原生对话框。
- 菜品新增、修改、筛选分页和删除等功能继续连接已有后端。

字体优先级为 SF Pro Display、SF Pro Text、Apple 系统字体及 Windows 系统字体。未安装 SF Pro 时使用系统后备字体；项目没有分发苹果字体文件。

## 查看方法

双击桌面 `cqwm` 中的 **启动项目.cmd**，在本地窗口输入 MySQL 密码，然后打开 `http://localhost:8080/#/login`。若浏览器保留旧页面，请按 `Ctrl+F5`。

当前未启动连接真实 MySQL 的正式服务。临时预览与浏览器验证使用独立 H2 数据库，本机业务数据未修改。

## 已验证

- 正确/错误密码登录、关闭登录框、退出登录。
- 功能入口登录后跳转到对应管理页。
- 菜品新增、图片表单、口味回显、修改、筛选及删除。
- 工作台、员工、分类、统计、订单与套餐入口。
- 320、390、768、1024、1440、1920 像素宽度下的布局，手机导航和编辑弹窗。
- 尊重系统减少动画设置；浏览器未出现脚本错误。

图片上传接口在本轮页面检查中使用模拟响应；没有重新执行真实 OSS 上传。后端业务代码未因本轮视觉更新而变更。
